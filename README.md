# Aprendizaje Profundo aplicado al Análisis Social
Este repositorio contiene el material y recursos correspondientes al curso de "Aprendizaje Profundo aplicado al Análisis Social". 

Este curso forma parte del Máster en Análisis Social Aplicado (DaSoc) de la Universidad de Granada. Para más información sobre el programa, consulta la [guía docente oficial](https://masteres.ugr.es/dasoc/docencia/plan-estudios/guia-docente/MD6/56/1/8).
